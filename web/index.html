      Connections & scope

      Account access and local installations

      Connect your accounts

      Open /mcp in Claude and select a server to sign in. For configured OAuth servers in Codex:

      codex mcp login <server>

      In Gemini, use /mcp auth <server>. Each agent manages its own account connection.

      Your installations stay local

      Each MCP uses the access scope configured in your agent. Shared skill files live in your user profile.

      Hosted MCPs and bundled system skills are updated by their providers. Local updates preserve backups and stop at conflicting edits.

      Suggested additions are reviewed separately. Missing tools are shown for review and are not automatically reinstalled.
