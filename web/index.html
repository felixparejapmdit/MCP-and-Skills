      Sign-in and scope

      Connect your accounts

      For a server awaiting sign-in, open /mcp in Claude Code and select the server. In Codex, authenticate a configured OAuth server with:

      codex mcp login <server>

      In Gemini CLI, use /mcp auth <server>. Each client keeps its own connection.
